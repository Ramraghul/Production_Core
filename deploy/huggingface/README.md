# Production Core

A Manufacturing Execution System for a vehicle assembly plant, built on
Node-RED. Seven production lines, 43 stations, ISO 22400 OEE, full as-built
genealogy and supplier-lot recall analysis.

- **Plant HMI** - the page you are looking at
- **Node-RED flows** - `/red`
- **REST API and Swagger** - `/api-docs`
- **Line board served by the flows** - `/factory/board`

Source and full documentation: see the repository this Space was built from.
